# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Game masters (DMs) running D&D 5e games, designing bespoke character, NPC, location, session-log, and party-tracker sheets for their table instead of relying on generic or official form-fill PDFs.

## Product Purpose

A local-first, precise visual layout tool for building print-quality D&D sheets. Users drop and arrange typed elements (boxes, fields, value badges, trackers, tables, text, rules) onto a fixed-size page grid, then print or export the result.

## Positioning

A grid-snapped, print-quality sheet designer purpose-built for D&D — offering DM-specific templates (NPC, location, session log, party tracker) and layout precision that generic form-fill PDFs or documents don't provide.

## Operating Context

Single-user, browser-based editing session against one document at a time. Users pick a page size (A5/A4/HALF/LETTER), start from a template or blank grid, and compose a sheet using the toolbar's element types, then rely on print output (browser print / PDF) as the delivery path.

## Capabilities and Constraints

- Local-first: all document data persists client-side (TanStack DB/localStorage-backed collection); no account, login, or backend sync.
- Print-first: layouts are designed against real page dimensions (mm) and margins; output must remain print-accurate.
- Element types: box, field, value, tracker, table, text, rule — each with grid-snapped bounds.
- Built-in templates: Character overview, NPC, Location/town, Session log, Party tracker, Blank page.
- Geared toward D&D 5e terminology and conventions (ability scores, AC, HP, skills, spells), not built for system-agnostic use, though nothing prevents relabeling fields.

## Brand Commitments

## Product Principles

- Print accuracy over screen-only convenience — what the user builds must look right on paper.
- Precision and control (grid snapping, exact bounds) over freeform, loose layout.
- DM-first templates that generic tools skip (NPC, location, session log, party tracker), not just a character sheet clone.
- Local-first and private by default — no accounts, no server dependency for core editing.
- D&D 5e conventions guide terminology and defaults; broader system compatibility is a non-goal, not a blocker.
